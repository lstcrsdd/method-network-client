# Скрипты

| Скрипт | Что делает |
|---|---|
| `bootstrap.ps1` | скачивает `sing-box.exe` и `wintun.dll` в `../Resources` |
| `verify-service.ps1` | приёмка привилегированной части: служба, канал, остановка начисто, возврат после падения |
| `preview.ps1` | живая проверка интерфейса: запустить клиент и снять окно, обойти разделы, поймать заставку |
| `build-installer.ps1` | публикует клиент одним файлом и пакует установщик (Inno Setup) |

## Установщик

```powershell
powershell -ExecutionPolicy Bypass -File build-installer.ps1
```

Публикует клиент одним самодостаточным файлом, кладёт рядом библиотеку общего
ядра и собирает `Installer\Output\Method-Setup-<версия>.exe`. Версия берётся из
`Directory.Build.props` — оттуда же, откуда её берут проекты, чтобы номер в
установщике и в свойствах файла не разъезжались.

Сборка останавливается, если нет движка (`Resources\sing-box.exe`,
`wintun.dll`) или библиотеки ядра (`core\build\method_core_ffi.dll`). Без
первого клиент не поднимет туннель вовсе, без второй маршруты выбирает сам
движок — без замеров, объяснений и памяти между запусками. Выпускать такое под
видом готового клиента нельзя, поэтому проверка стоит до сборки, а не после.

Ключ `-SkipPublish` берёт уже собранное из `publish\win-x64` — для правки
самого `Method.iss`, когда клиент пересобирать незачем.

Нужен [Inno Setup](https://jrsoftware.org/isinfo.php):
`winget install JRSoftware.InnoSetup`.

Подписи кода нет. SmartScreen будет предупреждать при первом запуске, и тем
громче, что рядом ставится сетевой драйвер Wintun; как включить подпись —
сказано в комментарии внутри `Installer\Method.iss`.

## Приёмка службы

```powershell
powershell -ExecutionPolicy Bypass -File verify-service.ps1
```

Нужны права администратора. Без ключей проверки только читающие. Ключ `-Full`
добавляет разрушающие: служба останавливается и убивается, туннель при этом
разрывается — в разгар работы гонять не надо. Ключ `-Install` перед проверками
запускает установку.

## Проверка интерфейса

```powershell
powershell -ExecutionPolicy Bypass -File preview.ps1 -Build -Sections Overview,Servers,Settings
```

Собирает, запускает клиент, ставит окно на свободный экран и снимает разделы.
Снимок идёт через `PrintWindow` с `PW_RENDERFULLCONTENT` — окно не вылезает на
передний план, и за машиной можно работать дальше. Разделы переключаются через
доступность, а не щелчком по координатам: щелчок отбирает фокус и промахивается,
стоит подписи переехать.

Серия кадров — так ловят заставку запуска и другое движение:

```powershell
powershell -ExecutionPolicy Bypass -File preview.ps1 -Frames 8 -EveryMs 300 -Name boot
```

Ключ `-Screen Primary` переносит окно на основной экран. По умолчанию —
дополнительный, чтобы не мешать тому, кто за машиной работает.

Скрипт гасит только свою отладочную сборку. Привилегированную часть он отличает
по недоступной командной строке и не трогает: остановить её значит разорвать
туннель.
