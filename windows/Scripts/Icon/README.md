# Знак

Иконка приложения собирается из вектора, а не хранится готовым растром: растр
нельзя ни поправить, ни отдать на другую платформу, ни пересобрать в размере,
которого в нём нет.

```powershell
dotnet run --project Scripts\Icon\svg2ico.csproj -- `
  Method.App\Assets Method.App\Assets\app.ico sheet.png
```

Первый параметр — каталог с векторами, второй — куда положить иконку, третий
(необязательный) — полоса размеров на тёмном и светлом фоне для глазной
проверки.

Одиночный вектор в PNG, чтобы смотреть правки крупно:

```powershell
dotnet run --project Scripts\Icon\svg2ico.csproj -- `
  Method.App\Assets\icon.svg big.png 256
```

## Почему векторов три

| Файл | Размеры | Чем отличается |
|---|---|---|
| `icon-small.svg` | 16–24 | только силуэт литеры: ни свечения, ни солнца, ни обводки |
| `icon-medium.svg` | 32–64 | солнце меньше, две полосы вместо четырёх, размытие втрое слабее |
| `icon.svg` | 128–256 | полный знак |

Это не украшательство. Свечение, обводка и полосы заданы в единицах холста
512: на 16 px обводка в три единицы — девять сотых пикселя, то есть её нет, а
размытие в семь единиц накрывает знак целиком. Один вектор на все размеры даёт
либо пустой силуэт внизу, либо голую плашку вверху — проверено глазами, полоса
размеров это показывает сразу.

Каждый размер рисуется **из исходного вектора**, а не уменьшением большого
растра: при уменьшении тонкие линии превращаются в кашу.
