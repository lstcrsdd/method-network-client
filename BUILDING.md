# Сборка из исходников

Клиент собирается из двух частей: движок выбора маршрута на Rust и
приложение на SwiftUI. Ядро **sing-box** в репозитории не хранится — его
скачивает `bootstrap.sh` с официального релиза SagerNet.

## Что нужно

* macOS 14+ на Apple Silicon
* Xcode 15+ (`sudo xcodebuild -license accept` — один раз)
* Rust (`rustup`), стабильная ветка
* XcodeGen — ставится скриптом ниже

## Шаги

```sh
cd macos
./Scripts/bootstrap.sh          # sing-box + XcodeGen + проверка лицензии
.tools/xcodegen/bin/xcodegen generate
open Method.xcodeproj
```

Движок собирается автоматически при сборке приложения: цель `Method`
вызывает `core/Scripts/build-macos.sh`, который собирает статическую
библиотеку и заголовок для Swift.

Отдельно движок можно проверить так:

```sh
cd core && cargo test
```

## Релизная сборка

```sh
cd macos && ./Scripts/release.sh
```

Скрипт собирает **вне** синхронизируемых папок (iCloud навешивает
расширенные атрибуты уже после подписи, и проверка подписи падает),
проверяет подпись после архивации, считает sha256 и печатает готовую
команду публикации. Сам он ничего не публикует.

## Почему приложение подписано ad-hoc

У проекта нет платного аккаунта Apple, поэтому нет ни Developer ID, ни
нотаризации. Следствия описаны в заметках к релизу: установка идёт командой
в Терминале, а macOS может попросить подтвердить системную службу вручную.
Скрипт выпуска готов к нотаризации — она включается одной переменной, когда
аккаунт появится.
